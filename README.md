# Healthify - Smart Healthcare Access System

Healthify is a modern web application designed to bridge healthcare access inequality through smart analysis and planning.

## Features

- **Emergency Assistance**: Quick access to emergency services and information.
- **Doctor Directory**: Find and book appointments with healthcare professionals.
- **Hospital Locator**: Locate nearby hospitals and medical centers.
- **Specialties**: Explore various medical specialties.
- **Health Planning**: Tools for analyzing and planning healthcare access.

## Technologies Used

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Animations**: GSAP, Framer Motion
- **Maps**: Leaflet
- **Icons**: Lucide React
- **Data Fetching**: TanStack Query (React Query)

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or yarn

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/Adithya-devcoder/HealthCare-Access-Inequality-Analysis-and-Planning-System.git
   ```

2. Navigate to the project directory:
   ```sh
   cd HealthCare-Access-Inequality-Analysis-and-Planning-System
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

### Development

Start the development server:
```sh
npm run dev
```

### Build

Build the project for production:
```sh
npm run build
```
